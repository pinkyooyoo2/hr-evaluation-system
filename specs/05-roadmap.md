# 개발 단계 로드맵

## Phase 1: 프로젝트 구성 + 개발 환경
- Vue 3 + Vite 프론트엔드 초기 설정
- Django + DRF 백엔드 초기 설정
- PostgreSQL 연결 준비
- 프로젝트 폴더 구조 구성
- 기본 의존성 설치

## Phase 2: 로그인 + 기본 관리자
- 사번/비밀번호 기반 로그인
- 사용자 역할 구분
- 기본 관리자 계정 자동 생성
- 세션 또는 JWT 방식은 단순하게 구성
- 기본 권한 체크

## Phase 3: 팀, 사용자, 평가 항목 관리
- 팀 추가/수정/삭제
- 사용자 추가/수정/삭제
- 팀별 매니저 지정
- 평가 항목 생성/수정/삭제
- 가중치 합계 100 검증

## Phase 4: 매니저 평가 입력
- 팀 직원 목록 확인
- 평가 항목별 1~5점 입력
- 임시 저장 기능
- 진행률 표시
- 제출 후 수정 불가

## Phase 5: 점수 계산 + 팀 보너스 + 응답 현황 + CSV 다운로드
- 개인 평가 점수 계산
- 최종 점수 계산 및 범위 제한
- 팀 보너스 반영
- 응답 현황 조회
- 미제출 매니저 포함 현황 확인
- CSV 다운로드 구현

## 완료 기준
- 로그인/권한 흐름이 동작한다.
- 관리자와 매니저/직원의 화면이 분리된다.
- 평가 데이터가 저장되고 계산된다.
- 최종 점수가 출력된다.
- CSV 다운로드가 동작한다.
