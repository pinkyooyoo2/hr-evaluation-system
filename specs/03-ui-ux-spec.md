# UI/UX 요구 사항

## 1. 디자인 방향
- Tabler 라이브러리를 사용한다.
- Bootstrap 5 기반으로 구성한다.
- 흰 배경을 기본으로 한다.
- 장식 요소는 최소화한다.
- 깔끔하고 단순한 관리자형 인터페이스를 사용한다.

## 2. 레이아웃
- 좌측 메뉴 + 우측 콘텐츠 구조를 사용한다.
- 좌측 메뉴는 역할별로 메뉴를 구분한다.
- 오른쪽 영역에 메인 콘텐츠를 표시한다.

## 3. 화면 구성
### 관리자 화면
- 대시보드 또는 요약 화면
- 팀 관리 화면
- 사용자 관리 화면
- 평가 항목 관리 화면
- 응답 현황 화면
- 팀 보너스 입력 화면
- 결과 다운로드 화면

### 매니저 화면
- 평가 항목 목록
- 평가 입력 화면
- 임시 저장 상태 표시
- 진행률 표시
- 제출 완료 상태 표시

### 직원 화면
- 본인 점수 조회 화면

## 4. 화면 동작 요구사항
- 입력 폼은 단순한 CRUD 형태로 구성한다.
- 진행률 표시를 숫자 또는 게이지로 표시한다.
- 제출 전에는 수정 가능하지만, 제출 후에는 읽기 전용 상태로 전환한다.
- 탭 또는 메뉴를 통해 역할별 화면 전환이 가능하다.

## 5. UX 원칙
- 화면은 직관적이어야 한다.
- 불필요한 애니메이션을 넣지 않는다.
- 입력 필드 명칭은 명확하게 한다.
- 에러 메시지는 간단하게 표시한다.
