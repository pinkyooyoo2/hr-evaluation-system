# 기능 요구 사항

## 1. 공통 기능
### 1.1 로그인
- 사번을 사용자 이름으로 사용한다.
- 비밀번호로 로그인한다.
- 역할에 따라 접근 가능한 화면이 다르다.

### 1.2 역할
다음 3가지 역할만 존재한다.
- 관리자
- 매니저
- 직원

## 2. 관리자 기능
### 2.1 기본 관리자 계정
앱 시작 시 관리자 계정이 없으면 아래 계정을 자동 생성한다.
- 성명: ADMIN
- 사번: ADMIN
- 비밀번호: admin1234!

### 2.2 팀 관리
- 팀 추가
- 팀 수정
- 팀 삭제
- 팀별 매니저 1명 지정
- 매니저는 팀에 고유하게 연결된다.

### 2.3 사용자 관리
- 사용자 추가
- 사용자 수정
- 사용자 삭제
- 역할 지정 가능
- 팀 소속 지정 가능

### 2.4 평가 항목 관리
- 항목 추가
- 항목 수정
- 항목 삭제
- 항목별 가중치 설정
- 가중치 합계는 100이어야 함

### 2.5 응답 현황 조회
- 전체 팀 또는 개인별 응답 상태 확인
- 미제출 매니저 목록 포함
- 제출 여부/미제출 여부 표시

### 2.6 팀 보너스 점수
- 관리자가 팀을 선택한다.
- 0~10점 범위의 보너스 점수를 입력한다.
- 선택 팀의 모든 직원 점수에 일괄 반영한다.

### 2.7 CSV 다운로드
- 평가 결과를 CSV 형식으로 다운로드한다.
- 엑셀에서 열 수 있는 CSV 파일을 생성한다.

## 3. 매니저 기능
### 3.1 평가 대상
- 매니저는 본인이 속한 팀의 직원만 평가한다.
- 각 팀은 매니저 1명만 지정된다.

### 3.2 평가 입력
- 평가 항목별로 1~5점 선택
- 각 항목은 별도 점수 선택값으로 입력
- 임시 저장 가능
- 진행률 표시

### 3.3 제출 규칙
- 제출 후에는 수정 불가
- 중복 응답 방지

## 4. 직원 기능
### 4.1 점수 확인
- 직원은 본인의 최종 점수를 조회할 수 있다.
- 직원은 본인의 점수에 대해서만 볼 수 있다.

## 5. 점수 계산 규칙
- 개인 평가 점수 = 항목별 (점수 ÷ 5 × 가중치) 합산
- 최종 점수 = 개인 평가 점수 + 팀 보너스 점수
- 최종 점수는 최소 0, 최대 100

### 계산 예시
- 항목 가중치: 50, 30, 20
- 점수: 4, 5, 3
- 계산 결과
  - 4/5 × 50 = 40
  - 5/5 × 30 = 30
  - 3/5 × 20 = 12
  - 총합 = 82
- 팀 보너스 +5
- 최종 점수 = 87

## 6. 제약사항
- 추가 기능을 만들지 않는다.
- 팀에는 매니저가 1명이어야 한다.
- 평가 항목 가중치 합계는 100이어야 한다.
- 점수 범위는 0~100으로 제한한다.
- 한 번 제출된 평가는 수정할 수 없다.
