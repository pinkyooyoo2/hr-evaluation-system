# 프로젝트 개요

## 1. 목적
이 시스템은 팀 단위 인사평가를 위해 관리자, 매니저, 직원의 역할별로 평가를 관리하고 결과를 계산하는 간단한 HR 평가 시스템이다.

## 2. 범위
본 프로젝트는 다음 기능에 한정한다.
- 로그인 및 역할 기반 접근 제어
- 관리자 관리 기능
- 팀 관리 기능
- 사용자 관리 기능
- 평가 항목 관리
- 매니저의 평가 입력
- 점수 계산 및 보너스 반영
- 응답 현황 확인
- CSV 엑셀 다운로드

## 3. 비범위
다음 항목은 이번 프로젝트에 포함하지 않는다.
- 소셜 로그인
- 이메일/OTP 인증
- 다중 회사 구조
- 복잡한 조직도 시각화
- 고급 리포트 분석
- 실시간 협업 기능

## 4. 사용자 역할
### 관리자
- 시스템 전체 설정 및 데이터 관리
- 팀, 사용자, 평가 항목 관리
- 점수 계산과 결과 조회
- 팀 보너스 입력

### 매니저
- 자신의 팀 직원만 평가
- 평가 제출/임시 저장
- 자기 팀 응답 현황 확인

### 직원
- 본인의 최종 점수 확인

## 5. 기본 규칙
- 사번과 비밀번호로 로그인한다.
- 팀별로 매니저는 1명이다.
- 평가 항목은 가중치 합계가 100이어야 한다.
- 한 번 제출한 평가는 수정할 수 없다.
- 최종 점수는 0~100 범위로 제한한다.

## 6. 프로젝트 방향성
- 최소 필수 기능 중심
- 구현 속도 우선
- 단순 CRUD 기반 구조
- 유지보수보다 기능 완성 우선
